participant "Cổng VietQR / PayOS\n(Payment Gateway)" as Gateway #EDE9FE
database "CSDL MySQL\n(Database)" as DB #FEF3C7

== GIAI ĐOẠN 1: TẠO ĐƠN HÀNG VÀ MÃ THANH TOÁN VIETQR ==

User -> UI : 1. Chọn gói tập &\nbấm "Thanh toán VietQR"
activate User
activate UI

UI -> Server : 2. POST /api/payments/create-order\n{\n  packageId: 3,\n  memberId: 101\n}
activate Server

Server -> DB : 3. INSERT INTO payments\n(payment_code, amount, status)\nVALUES ('PAY-8829', 5800000, 'PENDING')
activate DB
DB --> Server : 4. Ghi nhận hóa đơn tạm thời
deactivate DB

Server -> Gateway : 5. Tạo giao dịch QR Sandbox\nkèm mã thanh toán & số tiền
activate Gateway
Gateway --> Server : 6. Trả về Link ảnh QR\n& paymentCode đối soát
deactivate Gateway

Server --> UI : 7. Trả về mã VietQR\nkèm kênh WebSocket lắng nghe
UI --> User : 8. Hiển thị mã QR ngân hàng\nkèm đồng hồ đếm ngược 15 phút
deactivate UI

== GIAI ĐOẠN 2: KHÁCH HÀNG CHUYỂN KHOẢN MOBILE BANKING ==

User -> Gateway : 9. Mở App ngân hàng quét mã VietQR\n& xác thực chuyển khoản
activate Gateway
Gateway -> Gateway : 10. Hệ thống ngân hàng khớp lệnh\nchuyển tiền thành công

== GIAI ĐOẠN 3: XỬ LÝ WEBHOOK TỰ ĐỘNG & KÍCH HOẠT GÓI TẬP ==

Gateway -> Server : 11. POST /api/payments/webhook\n{\n  paymentCode: 'PAY-8829',\n  amount: 5800000,\n  signature: 'hmac_sha256_hash'\n}
deactivate Gateway

Server -> Server : 12. Kiểm tra tính hợp lệ\ncủa chữ ký số HMAC SHA256

Server -> DB : 13. SELECT status FROM payments\nWHERE payment_code = 'PAY-8829'
activate DB
DB --> Server : 14. status = 'PENDING'\n(Chưa đối soát, hợp lệ)

Server -> DB : 15. BEGIN TRANSACTION
Server -> DB : 16. UPDATE payments\nSET status = 'PAID', paid_at = NOW()\nWHERE payment_code = 'PAY-8829'

Server -> DB : 17. UPDATE memberships\nSET status = 'ACTIVE'\nWHERE id = membershipId

Server -> DB : 18. COMMIT TRANSACTION
DB --> Server : 19. Giao dịch CSDL hoàn tất
deactivate DB

Server --> Gateway : 20. HTTP 200 OK\n(Xác nhận đã xử lý Webhook)

Server -> UI : 21. Gửi sự kiện WebSocket (Socket.io):\n{ event: 'PAYMENT_SUCCESS', membershipId: 101 }
activate UI

UI --> User : 22. Tự động chuyển trang thông báo:\n"Kích hoạt gói tập thành công!"\n& cấp quyền check-in tức thì
deactivate UI
deactivate Server
deactivate User

@enduml
